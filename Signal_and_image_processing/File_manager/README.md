# File Manager - библиотека для работы с файлами в Java

**File Manager** — это библиотека на Java для создания проводника файлов с графическим интерфейсом. Она позволяет выбирать изображения и видео файлы, выполнять основные файловые операции и интегрируется с программами обработки медиаданных.

## Полный функционал

### Основные возможности

- **Навигация по файловой системе** - переход по папкам, подъем на уровень выше, домашняя директория
- **Просмотр файлов** - табличное представление с информацией о размере, типе и дате изменения
- **Файловые операции**:
  - Создание папок и файлов
  - Удаление файлов и папок (с подтверждением)
  - Отмена удаления (Ctrl+Z)
- **Выбор медиафайлов** - поддержка изображений и видео форматов
- **Фильтрация** - по типам файлов (все, jpg, png, mp4, и др.)
- **Контекстные меню** - интеллектуальные меню в зависимости от контекста выделения

### Поддерживаемые форматы

**Изображения:** jpg, jpeg, png, gif, bmp, tiff, raw  
**Видео:** mp4, avi, mov, mkv, wmv, flv, webm

## Класс FileManager

Основной класс библиотеки, реализующий интерфейс проводника файлов.

### Конструкторы

- `FileManager()` - создает файловый менеджер с текущей рабочей директорией

### Методы обратного вызова (Callbacks)

- `void setOnImageSelected(Consumer<String> listener)` - устанавливает обработчик для выбора одного изображения
- `void setOnImagesSelected(Consumer<String[]> listener)` - устанавливает обработчик для выбора нескольких изображений
- `void setOnFolderSelected(Consumer<String> listener)` - устанавливает обработчик для выбора папки

### Основные методы

- `void showFileManager()` - отображает окно файлового менеджера
- `void close()` - закрывает окно файлового менеджера
- `File getCurrentDirectory()` - возвращает текущую директорию
- `void setCurrentDirectory(File directory)` - устанавливает текущую директорию

### Элементы управления

**Панель инструментов:**
- **Up** - переход на уровень выше
- **Home** - переход в домашнюю директорию
- **Folder->** - переход в выделенную папку
- **Folder+** - создание новой папки
- **File+** - создание нового файла
- **Delete** - удаление выделенных объектов
- **Launch** - запуск выделенных медиафайлов

**Фильтрация:**
- Выпадающий список для выбора типа файлов (all, jpg, png, mp4, и др.)

**Навигация:**
- Поле ввода пути с валидацией
- Автоматическое восстановление при вводе некорректного пути

## Особенности интерфейса

### Контекстные меню

**По пустому месту:**
- New folder - создание папки
- New file - создание файла
- Cancel (Ctrl+Z) - отмена последней операции (если доступно)

**Для одиночного выделения:**
- **Папка:** Open, Delete
- **Медиафайл:** Launch, Delete
- **Другой файл:** Delete

**Для множественного выделения:**
- **При клике на папку:** Open [имя], Delete [имя], Delete all (N items), Launch all (M items)
- **При клике на файл:** Launch [имя], Delete [имя], Delete all (N items), Launch all (M items)

### Управление с клавиатуры

- **Enter** - запуск медиафайлов или переход в папку
- **Delete** - удаление выделенных объектов
- **Ctrl+Z** - отмена последнего удаления
- **ЛКМ по пустой области** - сброс выделения

### Функция отмены (Undo)

- Сохраняет историю операций удаления
- Восстанавливает файлы и папки в исходные расположения
- Доступна через Ctrl+Z или контекстное меню
