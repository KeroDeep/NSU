МДП Анализатор - Программа для анализа МДП структур

## Описание

Программа **МДП Анализатор** представляет собой расширенную реализацию моделирования металл-диэлектрик-полупроводник (МДП) структур, поддерживающую как *n*-типа, так и *p*-типа полупроводники с учётом режимов обогащения, обеднения и инверсии.

## Структура репозитория

```
Microelectronics/
├── build.bat         # Скрипт сборки EXE-файла из исходного кода
├── build.spec        # Конфигурационный файл для PyInstaller
├── logo.png          # Иконка приложения (отображается в заголовке окна)
├── main.exe          # Исполняемый файл для Windows (готовое приложение)
├── main.py           # Исходный код программы на Python
├── README.md         # Документация проекта с описание функционала
└── requirements.txt  # Список зависимостей Python для установки
```


## Основные возможности

- **Точный расчёт** вольт-фарадной характеристики в режимах обогащения, обеднения и инверсии (приближение низкой частоты, где в сильной инверсии ёмкость возвращается к значению диэлектрической ёмкости).

- Поддержка **n-типа** (доноры, напряжение от $0$ до $-V$) и **_p_-типа** (акцепторы, напряжение от $0$ до $+V$) полупроводников.

- Одновременное отображение **четырёх графиков**:

  - Ёмкость от напряжения.

  - Ширина области пространственного заряда.

  - Поверхностный потенциал.

  - Максимальное электрическое поле.

- **База материалов**:

  - Полупроводники: $Si$, $Ge$, $GaAs$.

  - Диэлектрики: $SiO_2$, $Si_3N_4$, $HfO_2$, $Al_2O_3$.

  - Возможность **ручного ввода** диэлектрической проницаемости.

- **Гибкие параметры**:

  - Толщина диэлектрика: $0.1–1000$ $нм$.

  - Площадь контакта: $0.001–1000$ $мм^2$.

  - Концентрация легирующих примесей (доноров или акцепторов): мантисса $0.1–9.99$, степень $10^{10}–10^{25}$ $см^{-3}$.

  - Температура: $1–1500$ $К$.

- **Экспорт результатов**:

  - Сохранение данных в текстовый файл (ASCII).

  - Экспорт графиков в PNG и PDF.

- **Удобство использования**:

  - **Два языка интерфейса**: русский и английский.

  - **Масштабирование интерфейса** ($80\%–120\%$ с шагом $4\%$).

  - Автоматическая валидация ввода.

  - Кнопка сброса параметров.

  - Интерактивные графики с навигацией.

## Соответствие учебному заданию

Программа **полностью выполняет** все требования задания и расширяет их:

- Ввод всех параметров полупроводника и структуры, включая тип (*n* или *p*).

- База данных для кремния, германия и арсенида галлия.

- Расчёт ёмкости в общем случае, включая режимы обогащения и инверсии.

- Шаг по напряжению $0.01$ $В$.

- Построение вольт-фарадной характеристики.

- Сохранение результатов в текстовом (ASCII) формате.

- Учёт падения напряжения в диэлектрике и ОПЗ через непрерывность индукции.

- Раздельный ввод концентрации (мантисса и степень), расчёт собственной концентрации с учётом эффективных масс.

## Установка и запуск

### Готовое приложение

1. Скачайте `main.exe`.

2. Запустите двойным кликом.

3. Программа готова к работе.

### Из исходного кода

```bash
pip install -r requirements.txt
python main.py
```
