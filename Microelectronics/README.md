# МДП Анализатор - Программа для анализа МДП структур

## Описание

Программа **МДП Анализатор** представляет собой расширенную реализацию моделирования металл-диэлектрик-полупроводник (МДП) структур. В то время как условие задачи требовало расчета только для режима обеднения, данная версия реализует полный анализ C-V характеристик с дополнительными возможностями.

## Структура репозитория

```
Microelectronics/
├── build.bat         # Скрипт сборки EXE-файла из исходного кода
├── build.spec        # Конфигурационный файл для PyInstaller
├── logo.png          # Иконка приложения (отображается в заголовке окна)
├── main.exe          # Исполняемый файл для Windows (готовое приложение)
├── main.py           # Исходный код программы на Python
├── README.md         # Документация проекта с описание функционала
└── requirements.txt  # Список зависимостей Python для установки
```

## Основные возможности

### Расширенный анализ характеристик

#### **Полные C-V характеристики**

- **Вольт-фарадные характеристики** во всех режимах работы: накопление, обеднение, инверсия

- **Ширина области пространственного заряда** (ОПЗ) в зависимости от напряжения

- **Поверхностный потенциал** полупроводника

- **Максимальное электрическое поле** в структуре

#### Расширенные параметры моделирования

- **Расширенная база материалов**: 

  - Полупроводники: кремний (Si), германий (Ge), арсенид галлия (GaAs)

  - Диэлектрики: SiO₂, Si₃N₄, HfO₂, Al₂O₃

- **Полный набор физических параметров**:

  - Запрещенная зона, диэлектрическая проницаемость

  - Эффективные массы дырок и электронов

  - Уровень доноров, концентрация легирования (10¹⁰-10²⁵ см⁻³)

  - Температура (1-1500 K)

- **Геометрические параметры**: 

  - Толщина диэлектрика: 0.1-1000 нм

  - Площадь контакта: 0.001-1000 мм²

  - Диапазон напряжений: ±100 В

#### Возможности экспорта

- **Сохранение данных в ASCII формате** (полное соответствие требованию)

- **Экспорт графиков** в PNG и PDF с высоким разрешением

- **Детальный отчет** по всем параметрам структуры

### Дополнительные возможности

1. **Полный C-V цикл** - программа рассчитывает не только режим обеднения, но и режимы накопления и инверсии

2. **Расширенная физическая модель**:

   - Учет работы выхода металла и сродства к электрону

   - Расчет уровня Ферми в объеме полупроводника

   - Определение напряжения плоских зон

   - Учет инверсионного слоя

3. **Профессиональная визуализация**:

   - Одновременное отображение 4 характеристик

   - Интерактивные графики с масштабированием

   - Панель статистики и анализа

4. **Удобство использования**:

   - Базы данных материалов с предустановленными параметрами

   - Валидация вводимых данных

   - Автоматический сброс к настройкам по умолчанию

## Соответствие учебному заданию

### Полностью выполненные требования:

- Графический интерфейс для ввода всех параметров

- База данных материалов для Si и Ge с корректными параметрами

- Расчет и построение C-V характеристик

- Сохранение данных в ASCII формате

- Шаг напряжения 0.01 В

- Расчет ширины ОПЗ

### Дополнительно реализовано:

- Поддержка дополнительных материалов (GaAs, новые диэлектрики)

- Расчет полного C-V цикла, а не только режима обеднения

- Одновременная визуализация 4 различных характеристик

- Профессиональная панель анализа результатов

- Экспорт графиков в PDF/PNG форматы

- Интерактивная навигация по графикам

- Автоматическая валидация входных данных

## Преимущества данной реализации

## Установка и запуск

### Требования

- Windows 7/8/10/11

- Python 3.8+ (для сборки из исходного кода)

### Запуск готового приложения

1. Скачайте файл `main.exe`

2. Запустите `main.exe` двойным кликом

3. Программа готова к работе!
