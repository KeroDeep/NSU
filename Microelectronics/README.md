# МДП Анализатор - Программа для анализа МДП структур

## Описание

Программа **МДП Анализатор** предназначена для моделирования и анализа характеристик металл-диэлектрик-полупроводник (МДП) структур. Приложение предоставляет удобный графический интерфейс для расчета вольт-фарадных характеристик, анализа параметров полупроводников и визуализации результатов.

## Основные возможности

### 📊 Анализ характеристик
- **Вольт-фарадные характеристики** МДП структур
- **Ширина области пространственного заряда** (ОПЗ)
- **Поверхностный потенциал**
- **Электрическое поле** в структуре

### 🔧 Параметры моделирования
- **Выбор материалов**: база данных полупроводников и диэлектриков
- **Геометрические параметры**: толщина диэлектрика, площадь контакта
- **Электрические параметры**: диапазон напряжений, шаг расчета
- **Параметры полупроводника**: концентрация легирования, температура, эффективные массы

### 💾 Экспорт данных
- Сохранение расчетных данных в текстовом формате
- Экспорт графиков в форматы PNG и PDF
- Детальный анализ параметров структуры

## Установка и запуск

### Требования
- Windows 7/8/10/11
- Python 3.8+ (для сборки из исходного кода)

### Запуск готового приложения
1. Скачайте файл `main.exe`
2. Запустите `main.exe` двойным кликом
3. Программа готова к работе!

### Сборка из исходного кода
```bash
# Клонирование репозитория
git clone <repository-url>
cd Microelectronics

# Сборка приложения
.\build.bat
```
