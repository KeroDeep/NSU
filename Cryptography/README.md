# 🔐 Курс по криптографии

## 🎯 Структура курса

### 📚 Уровень 1: Основы криптографии

#### Задача 1.1: Классические шифры

**Цель:** Изучение базовых криптографических алгоритмов

**Требования:**
- Реализовать шифр Цезаря с произвольным сдвигом
- Создать шифр Виженера с ключевым словом  
- Реализовать шифр Атбаш (обратный алфавит)
- Визуализировать процесс шифрования/дешифрования
- Проанализировать стойкость шифров

#### Задача 1.2: Математические основы

**Цель:** Освоение математического аппарата криптографии

**Требования:**
- Реализовать алгоритм Евклида для НОД
- Создать функцию для вычисления символа Лежандра
- Реализовать тест простоты Ферма
- Построить графики криптографических функций
- Исследовать свойства простых чисел

#### Задача 1.3: Генерация случайных последовательностей

**Цель:** Изучение методов генерации псевдослучайных чисел

**Требования:**
- Реализовать линейный конгруэнтный генератор
- Создать генератор на основе регистра сдвига
- Сгенерировать криптографически стойкие последовательности
- Протестировать статистические свойства
- Визуализировать распределения

---

### 📚 Уровень 2: Симметричное шифрование

#### Задача 2.1: Блочные шифры

**Цель:** Изучение алгоритмов блочного шифрования

**Требования:**
- Реализовать алгоритм DES (упрощенная версия)
- Создать режимы работы ECB, CBC, CFB
- Визуализировать процесс раундового преобразования
- Проанализировать диффузию и конфузию
- Сравнить производительность режимов

#### Задача 2.2: AES реализация

**Цель:** Практическое освоение современного стандарта

**Требования:**
- Реализовать базовые операции AES: SubBytes, ShiftRows, MixColumns
- Создать полную версию AES-128
- Визуализировать преобразования состояния
- Протестировать на стандартных векторах
- Оптимизировать производительность

#### Задача 2.3: Поточные шифры

**Цель:** Изучение поточного шифрования

**Требования:**
- Реализовать RC4 потоковый шифр
- Создать самосинхронизирующийся потоковый шифр
- Проанализировать статистические свойства выхода
- Исследовать уязвимости поточных шифров
- Сравнить с блочными шифрами

**Цель:** Создание и анализ хеш-функций

**Требования:**

- Протестировать на коллизиях

#### Задача 3.2: HMAC и аутентификация

**Цель:** Изучение кодов аутентификации сообщений

**Требования:**
- Реализовать HMAC с различными хеш-функциями
- Создать систему проверки целостности файлов
- Протестировать стойкость к атакам
- Визуализировать процесс вычисления
- Сравнить различные реализации

#### Задача 3.3: Цифровые отпечатки и идентификация

**Цель:** Применение хеш-функций для идентификации

**Требования:**
- Создать систему проверки целостности данных
- Реализовать обнаружение дубликатов файлов

### 📚 Уровень 4: Асимметричная криптография

#### Задача 4.1: RSA криптосистема

**Цель:** Освоение первой асимметричной системы

**Требования:**
- Реализовать генерацию ключей RSA
- Создать функции шифрования/дешифрования
- Реализовать цифровую подпись RSA
- Проанализировать стойкость при разных размерах ключей
- Визуализировать математические преобразования

#### Задача 4.2: Криптосистема Эль-Гамаля

**Цель:** Изучение дискретного логарифмирования

**Требования:**
- Реализовать схему Эль-Гамаля для шифрования
- Создать цифровую подпись Эль-Гамаля
- Исследовать зависимость стойкости от группы
- Сравнить с RSA по производительности
- Визуализировать операции в группах

#### Задача 4.3: Криптография на эллиптических кривых

**Цель:** Освоение современных ECC методов

**Требования:**
- Реализовать арифметику эллиптических кривых
- Создать ECDH для обмена ключами
- Реализовать ECDSA для цифровых подписей
- Визуализировать операции на кривых
- Сравнить стойкость с RSA
