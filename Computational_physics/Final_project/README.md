# Курсовая работа

Решить задачу Коши для уравнения Гинзбурга–Ландау по явной схеме.
Производную по координате заменить на разностное отношение, полученную
систему ОДУ по времени решить методом Рунге–Кутты второго порядка
точности.

$$ \frac{\partial A}{\partial t} = \gamma A + (i b_1 - 1) {|A|}^2 A + (1 + i b_2) \frac{\partial^2 A}{\partial x^2}, \qquad 0 < x < 1 $$

## Граничные и начальные условия

$$ A(0, t) = A(1, t) = 0, \qquad A(x, 0) = x^2 (1 - x), \qquad b_1 = 10, \qquad b_2 = 1 $$

Вычислить зависимости от времени коэффициентов Фурье

$$ F_n (t) = \int^1_0 dx A(x, t)\, \sin(n \pi x) $$

и нарисовать фазовую кривую на плоскости $|F_1|$, $|F_2|$ и проследить
изменение характера фазовой траектории при росте $\gamma$.
