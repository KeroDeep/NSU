# 🐚 Курс по Bash

## 🎯 Структура курса

### 📚 Уровень 1: Основы

#### Задача 1.1: Приветствие

**Цель:** Создать первый скрипт

**Требования:**
- Скрипт должен выводить "Привет, мир!"
- Добавить вывод текущей даты и времени
- Показать текущего пользователя
- Вывести текущую рабочую директорию
- Сделать скрипт исполняемым

#### Задача 1.2: Системная информация

**Цель:** Научиться использовать системные команды

**Требования:**
- Вывести информацию о системе (`uname -a`)
- Показать использование диска (`df -h`)
- Отобразить свободную память (`free -h`)
- Вывести список запущенных процессов (`ps aux`)
- Форматировать вывод для читаемости

#### Задача 1.3: Работа с файлами

**Цель:** Освоить базовые файловые операции

**Требования:**
- Создать директорию `test_project`
- Внутри создать 5 текстовых файлов с разными именами
- В каждый файл записать текущую дату создания
- Вывести список созданных файлов с размерами
- Удалить директорию и все содержимое

---

### 📚 Уровень 2: Переменные и ввод данных

#### Задача 2.1: Персональный калькулятор возраста

**Цель:** Работа с переменными и пользовательским вводом

**Требования:**
- Запросить у пользователя имя
- Запросить год рождения
- Вычислить возраст
- Вывести персональное сообщение: "Привет, [имя]! Тебе [возраст] лет."
- Добавить проверку на корректность ввода года

#### Задача 2.2: Конвертер валют

**Цель:** Использование арифметических операций

**Требования:**
- Установить фиксированный курс USD к RUB (например, 90)
- Запросить у пользователя сумму в USD
- Вычислить эквивалент в RUB
- Форматировать вывод: "100 USD = 9000 RUB"
- Добавить поддержку конвертации в обе стороны

#### Задача 2.3: Генератор паролей

**Цель:** Работа со случайными числами и строками

**Требования:**
- Запросить у пользователя длину пароля
- Сгенерировать случайный пароль из букв и цифр
- Обеспечить минимальную длину 8 символов
- Вывести пароль пользователю
- Сохранить пароль в файл с текущей датой

---

### 📚 Уровень 3: Условия и операторы сравнения

#### Задача 3.1: Калькулятор с меню

**Цель:** Реализация сложных условий

**Требования:**
- Создать меню с операциями: +, -, *, /
- Запросить два числа у пользователя
- Реализовать проверку деления на ноль
- Обработать неверный выбор операции
- Выводить историю операций в файл

#### Задача 3.2: Валидатор файлов

**Цель:** Работа с файловыми проверками

**Требования:**
- Запросить у пользователя путь к файлу
- Проверить существование файла
- Проверить права доступа (чтение, запись, выполнение)
- Определить тип файла (обычный, директория, символьная ссылка)
- Вывести подробный отчет о файле

#### Задача 3.3: Система оценок

**Цель:** Использование case и множественных условий

**Требования:**
- Запросить у пользователя балл (0-100)
- Используя case, определить оценку:
  - 90-100: A
  - 80-89: B
  - 70-79: C
  - 60-69: D
  - 0-59: F
- Для каждой оценки дать текстовое описание
- Добавить проверку на корректность диапазона

### 📚 Уровень 4: Циклы

#### Задача 4.1: Таблица умножения PRO

**Цель:** Освоение вложенных циклов

**Требования:**
- Вывести таблицу умножения от 1 до 10
- Форматировать вывод в виде аккуратной таблицы
- Добавить возможность выбора диапазона
- Реализовать цветовое выделение четных/нечетных
- Предложить сохранить результат в файл

#### Задача 4.2: Анализатор логов

**Цель:** Обработка файлов в циклах

**Требования:**
- Прочитать файл лога (можно использовать `/var/log/syslog`)
- Найти все строки с ключевыми словами: ERROR, WARNING, INFO
- Подсчитать количество каждого типа сообщений
- Вывести топ-5 самых частых сообщений
- Сохранить отчет в отдельный файл

#### Задача 4.3: Монитор системы

**Цель:** Реализация бесконечных циклов

**Требования:**
- Создать монитор, который обновляется каждые 2 секунды
- Отображать: загрузку CPU, использование памяти, дисковое пространство
- Добавить цветовые индикаторы (зеленый/желтый/красный)
- Реализовать выход по нажатию клавиши 'q'
- Вести лог изменений

### 📚 Уровень 5: Функции

#### Задача 5.1: Модульный калькулятор

**Цель:** Создание многофайлового проекта

**Требования:**
- Создать отдельные функции для операций: +, -, *, /
- Реализовать функцию валидации входных данных
- Создать функцию логирования операций
- Добавить функцию вывода истории вычислений
- Организовать код в отдельные файлы

#### Задача 5.2: Рекурсивный обход директорий

**Цель:** Работа с рекурсивными функциями

**Требования:**
- Написать функцию для рекурсивного обхода директории
- Подсчитать общий размер всех файлов
- Найти самые большие файлы (топ-10)
- Определить количество файлов по типам (расширениям)
- Вывести древовидную структуру директорий

#### Задача 5.3: Система управления задачами

**Цель:** Создание интерактивного приложения

**Требования:**
- Реализовать функции: добавить, удалить, показать, отметить выполненной
- Хранить задачи в файле
- Добавить поиск по задачам
- Реализовать фильтрацию по статусу
- Добавить экспорт задач в CSV

### 📚 Уровень 6: Работа с файлами

#### Задача 6.1: Резервное копирование

**Цель:** Создание системы бэкапов

**Требования:**
- Копировать указанные директории с сохранением структуры
- Добавить сжатие в tar.gz
- Реализовать ротацию бэкапов (хранить только последние 7)
- Вести лог операций с временными метками
- Добавить проверку целостности архивов

#### Задача 6.2: Анализатор конфигурационных файлов

**Цель:** Парсинг структурированных файлов

**Требования:**
- Анализировать `/etc/passwd` и `/etc/group`
- Вывести список пользователей с их группами
- Найти пользователей с `/bin/bash` оболочкой
- Определить пользователей без пароля
- Сгенерировать отчет в HTML формате

#### Задача 6.3: Монитор изменений файлов

**Цель:** Отслеживание файловой системы

**Требования:**
- Мониторить указанную директорию на изменения
- Фиксировать: создание, удаление, изменение файлов
- Сохранять историю изменений с diff
- Отправлять уведомления при критических изменениях
- Реализовать режим реального времени и периодической проверки

### 📚 Уровень 7: Регулярные выражения и текстовые утилиты

#### Задача 7.1: Валидатор данных

**Цель:** Применение regex для валидации

**Требования:**
- Валидировать email адреса
- Проверять номера телефонов в формате +7(...)...-..-..
- Валидировать IP-адреса
- Проверять даты в формате DD.MM.YYYY
- Создать тестовый файл с разными данными для проверки

#### Задача 7.2: Парсер access.log

**Цель:** Анализ логов с помощью текстовых утилит

**Требования:**
- Определить топ-10 IP-адресов по количеству запросов
- Найти самые популярные страницы (URL)
- Выявить ошибочные запросы (4xx, 5xx)
- Посчитать трафик по каждому IP
- Построить временную шкалу запросов

#### Задача 7.3: Текстовый процессор

**Цель:** Создание инструмента для обработки текста

**Требования:**
- Подсчет слов, строк, символов
- Поиск и замена текста с поддержкой regex
- Удаление дубликатов строк
- Сортировка строк по различным критериям
- Форматирование вывода (выравнивание, отступы)
