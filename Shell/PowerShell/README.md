# ⚡ Курс по PowerShell

## 🎯 Структура курса

### 📚 Уровень 1: Основы

#### Задача 1.1: Системный инспектор

**Цель:** Изучение базовых команд PowerShell

**Требования:**
- Вывести информацию о системе (`Get-ComputerInfo`)
- Показать список запущенных служб
- Отобразить установленные программы
- Вывести сетевые интерфейсы и их настройки
- Создать красивый форматированный отчет

#### Задача 1.2: Работа с объектами

**Цель:** Понимание pipeline и объектов

**Требования:**
- Получить список процессов и отсортировать по CPU
- Отфильтровать процессы, использующие больше 100MB памяти
- Вывести результат в табличном формате
- Экспортировать результат в CSV файл
- Создать HTML отчет с цветовым кодированием

#### Задача 1.3: Управление файловой системой

**Цель:** Освоение файловых операций

**Требования:**
- Создать сложную структуру директорий
- Наполнить файлами с различным содержимым
- Изменить атрибуты файлов (ReadOnly, Hidden)
- Найти файлы по шаблону и выполнить операции
- Экспортировать структуру в XML

---

### 📚 Уровень 2: Переменные и ввод данных

#### Задача 2.1: Калькулятор ИМТ с классами

**Цель:** Работа с типами данных и вводом

**Требования:**
- Запросить вес и рост с валидацией
- Рассчитать ИМТ с точностью до 2 знаков
- Определить категорию (недостаток, норма, избыток)
- Выдать рекомендации на основе результата
- Сохранить историю расчетов

#### Задача 2.2: Генератор отчетов о системе

**Цель:** Использование переменных и форматирования

**Требования:**
- Собрать системную информацию в переменные
- Создать красивый отчет с секциями
- Добавить цветовое оформление
- Предложить выбор формата вывода (консоль, файл, HTML)
- Реализовать фильтрацию по категориям

#### Задача 2.3: Мастер настройки Windows

**Цель:** Интерактивные сценарии

**Требования:**
- Предложить меню настроек системы
- Реализовать изменение имени компьютера
- Настройка сетевых параметров
- Управление службами Windows
- Создание точек восстановления

---

### 📚 Уровень 3: Условия и операторы сравнения

#### Задача 3.1: Монитор здоровья системы

**Цель:** Сложные условия и операторы

**Требования:**
- Проверить загрузку CPU (>80% - критично)
- Проверить свободную память (<10% - критично)
- Проверить место на диске C: (<5GB - критично)
- Для каждого состояния выдать рекомендации
- Отправить уведомление при критических состояниях

#### Задача 3.2: Система контроля версий файлов

**Цель:** Работа с файловыми атрибутами

**Требования:**
- Сравнить две версии файла
- Определить тип изменений (добавление, удаление, изменение)
- Создать backup изменяемых файлов
- Ведение журнала изменений
- Откат к предыдущей версии

#### Задача 3.3: Умный установщик пакетов

**Цель:** Использование switch и проверок

**Требования:**
- Проверить наличие установленного ПО
- Определить архитектуру системы (x64/x86)
- Проверить наличие прав администратора
- Предложить установку недостающего ПО
- Логировать процесс установки

### 📚 Уровень 4: Циклы

#### Задача 4.1: Анализатор событий Windows

**Цель:** Обработка логов событий

**Требования:**
- Собрать события за последние 24 часа
- Сгруппировать по уровню (Error, Warning, Information)
- Найти наиболее частые источники ошибок
- Создать отчет с динамикой по часам
- Отправить уведомление о критических ошибках

#### Задача 4.2: Инвентаризация сети

**Цель:** Работа с сетевыми ресурсами

**Требования:**
- Просканировать диапазон IP-адресов
- Определить доступные хосты
- Собрать информацию об открытых портах
- Составить карту сети
- Экспортировать результаты в Excel

#### Задача 4.3: Монитор производительности в реальном времени

**Цель:** Создание дашборда

**Требования:**
- Отображать метрики в реальном времени
- Обновлять данные каждую секунду
- Цветовые индикаторы состояния
- Исторические графики изменений
- Система оповещений
